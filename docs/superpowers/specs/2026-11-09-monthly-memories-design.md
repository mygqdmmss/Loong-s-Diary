# 月袋与每日光影 · 设计

用户已通过交互预览选择：外层使用「月袋散记」，打开后使用「漂浮光影」；每一天一个气泡，再打开当天的一篇或多篇日记。

## 体验与范围

- 首页展示菜单增加「月袋」，沿用已有分类筛选、列表和网格。选择会保存在原 `homeViewMode` 偏好中。
- 每个有记录的月份是一只纸感月袋，露出该月最多两张照片或文字短笺，标注月份、记录天数及篇数。较早月份也必须完整出现。
- 打开月袋进入按日收纳的光影画布：照片使用柔软不规则轮廓；没有照片的日期使用正文摘句。气泡下方保留清晰日号，多篇时展示篇数。
- 布局大小和位置有变化，但保持稳定，气泡轻微呼吸浮动；点击时不会追逐移动目标。整个月最多 31 个节点，纵向浏览。
- 点开某一天进入当天篇目页，单篇日也经过该页；再进入现有可编辑日记详情。返回后，改日期、改分类和删除都会同步到正确的月袋和气泡。
- 月内可切换当前分类有记录的月份；空月份、空日期和错误状态都可返回或重试。
- 新模式使用现有照片和日记，不加入演示内容；音视频日记在没有图片封面时使用文字 / 媒体提示。

## 方案选择

已比较纸袋短笺和照片胶囊两种预览。用户选择混合：纸袋负责收纳感，内层照片气泡负责轻盈感。采用稳定错落的布局及克制动效，不使用持续碰撞的物理模拟。

## 数据与接入

- 保留 `ViewModeType.list=0`、`grid=1`，新增 `monthly=2`；未知保存值回退到列表。
- 按日记 `time.toLocal()` 归月归日，查询使用本地月初 / 日初至下一边界的半开区间。回收站不计入，分类筛选与原首页一致。
- 月份摘要通过可见日记的时间投影生成，不依赖首页 30/20 篇分页。月袋封面仅按需读取；进入月份时读取该月日记并归日。
- 新增可注入的月份数据源；Isar collection watch 使写入、编辑、导入、恢复与同步后的视图失效重载。关闭页面时取消订阅，异步结果不覆盖较新的选择。
- 月视图独立使用已有详情路由，避开旧卡片导航对分页列表下标的假设；返回后安全刷新已注册首页列表。
- 不改数据库 schema、备份格式、Rust 源码或现有图片文件。

## 外观与可用性

- 与当前浅深色主题协调，保留系统文字缩放。320px 宽度下日期和必要操作完整可见；大字体时扩大节点或减少同排节点。
- 纯文字节点与有图节点同等可点，缩略图失败时有有意设计的替代外观。
- 日号、篇数和语义标签不能依靠颜色区分，触摸目标至少 48px。尊重系统减少动态效果，动画在不可见路由停用。
- 只提供展示与阅读的轻互动；本版不加入拖拽持久化、AI 摘要、图片背景分割或数据迁移。

## 验收

1. 跨年、同日多篇、纯文字、分类、回收站、本地时间边界和 31 天月份分组正确。
2. 旧月份不受首页分页限制；详情中变更日期 / 分类或删除最后一篇后，计数与入口更新。
3. 实际 Flutter 组件在窄屏、浅深色、大字体和减少动画模式下可阅读、可操作；按月份到日期再到篇目可完整走通。
4. 现有测试与新增行为测试、变更文件分析通过，独立审阅通过，产出新 APK。旧 build 91 安装包单独保留。
